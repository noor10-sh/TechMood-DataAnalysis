# TechMood Data Analytics Bootcamp

## About the Bootcamp

The TechMood Data Analytics Bootcamp is a free learning opportunity for learners who wants to take their first step into the world of data analysis. It provides a clear introduction to data analysis, practical tools, business thinking, and the skills needed to turn raw data into useful insights and informed decisions.

The bootcamp combines technical knowledge with practical projects. Learners work through the complete data journey: collecting and preparing data, analyzing it, creating visualizations, communicating findings, and presenting recommendations.

## Bootcamp Goals

- Build a strong foundation in data analysis and business analytics.
- Learn how to extract, clean, explore, and interpret data.
- Use popular tools such as Excel, SQL, Python, and Power BI.
- Develop analytical thinking and problem-solving skills.
- Create dashboards, reports, and data stories that support better decisions.
- Build practical projects for a professional portfolio.
- Prepare for career opportunities in data and business analytics.

## Roadmap divides in 4 satges

### Stage 0 - Orientation and Identity Setup

- Understand the bootcamp structure and learning path.
- Create and improve a professional digital identity.
- Set up GitHub and LinkedIn profiles.
- Prepare a foundation for documenting and presenting practical work.

### Stage 1 - Data Analytics Core

- Understand the fundamentals of data analysis.
- Learn Excel for data analysis, formulas, and data quality improvement.
- Query and analyze data using SQL.
- Use Python for data analysis.
- Work with NumPy and pandas for data processing.
- Create charts and visualizations with Matplotlib.
- Build dashboards and reports with Power BI Desktop and Power BI Service.
- Write DAX measures and calculations in Power BI.

### Stage 2 - Applied Statistics, Business Analytics, and ETL

- Understand descriptive statistics and exploratory data analysis.
- Analyze frequencies, distributions, and relationships in datasets.
- Learn hypothesis testing and A/B testing.
- Understand ETL: extract, transform, and load data.
- Use data integration and preparation techniques with tools such as pandas and Power Query.
- Learn the basics of data modeling and the Star Schema.
- Connect data sources and create reliable analytical tables.
- Apply data storytelling and psychological principles to communicate insights effectively.

### Stage 3 - Capstone and Career Lab

- Complete a practical medical or business analytics capstone project.
- Work with real-world data and produce a professional analytical solution.
- Apply artificial intelligence concepts to support analysis where appropriate.
- Build a portfolio project that demonstrates technical and business skills.
- Create a professional CV and optimize it for Applicant Tracking Systems (ATS).
- Practice interviews and prepare for technical and behavioral questions.
- Develop communication, teamwork, and career-readiness skills.
